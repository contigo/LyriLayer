# LyriLayer

삼성 뮤직 전용 읽기 전용 가사 도우미. 재생/정지/탐색 등 음악 제어 없음.

## APK 빌드
GitHub Actions의 LyriLayer APK Build 워크플로에서 빌드 결과를 확인할 수 있습니다. 성공한 실행의 Artifacts에서 LyriLayer-APK를 내려받습니다. Debug APK이며 별도 고정 서명 키를 사용하지 않습니다.

## 실행
1. Android Studio에서 이 폴더를 Open. JDK 17, Android SDK 36, Gradle 8.13을 설치/선택한다. 이 배포본에는 Gradle wrapper JAR이 포함되지 않는다. 로컬 Gradle 8.13을 선택하거나 gradle wrapper --gradle-version 8.13 실행 후 gradlew.bat :app:assembleDebug (Windows).
2. Gradle Sync 후 갤럭시 실기기에 Run.
3. 라이브러리에서 음악 파일 권한 허용. 가사 일괄 수집 또는 곡별 검색.
4. 설정에서 알림 접근 허용 및 다른 앱 위에 표시 권한 허용, 플로팅 가사 ON.
5. 삼성 뮤직에서 음악 재생. 실시간 가사 탭과 오버레이 확인.

## 구현
- Kotlin, Compose Material 3, Room, WorkManager, OkHttp.
- MediaStore 공유 음악 목록, LRCLIB 검색, DB 우선 조회, 미검색 결과 24시간 캐시, 수동 편집 보호.
- Samsung Music 패키지 com.sec.android.app.music의 MediaSession 읽기 전용 폴링. 마지막 재생 위치와 elapsedRealtime 기반 보간, 150ms 갱신. LRC 구간 탐색은 이진 검색. 일시 정지 시 오버레이 숨김.
- 일반 가사 표시, LRC 입력 및 ms 보정, Google 검색 브라우저 열기 (자동 스크래핑하지 않음).
- WorkManager 일괄 검색 취소 및 재실행, 저장된 가사 재사용. 백그라운드 작업은 OS 제한 적용.

## 아직 미구현 / 검증 필요
- 삼성 갤럭시 실기기 테스트 필요.
- MP3 내장 가사 추출, LRC 파일 자동 탐색/가져오기/내보내기, 백업/복원, 새 파일 자동 감지, 오버레이 세부 스타일, 추가 온라인 검색 제공처는 후속 단계.
- 삼성 뮤직 MediaSession metadata 및 재생 위치 제공 여부, 앱 절전/화면 잠금/탐색 시 동작, 실제 권한과 터치 통과를 실기기에서 확인해야 한다.
- LRCLIB에서 찾지 못하는 곡이 있을 수 있으며 일반 가사는 시간 정보가 없어 자동 동기화되지 않는다. 온라인 제공처의 이용 조건과 가사 저작권 검토 후 배포할 것.
- 온라인 검색 시 제목, 가수, 앨범, 재생 시간 전송. 알림 내용과 음원 자체는 전송하지 않음.

## v0.1.7 — 고정 APK 서명
- Windows에서 `tools/setup-signing.ps1`을 한 번 실행해 전용 PKCS12 키 및 GitHub Actions Secrets를 등록합니다. 키와 비밀번호는 공개 저장소에 올리지 않습니다.
- 이후 모든 배포 APK는 동일 키로 재서명하고 apksigner 검증 및 zipalign 확인 후 등록합니다. Secrets 누락 시 빌드를 중단합니다.
- 기존 임시 debug 키로 설치된 앱은 해당 개인 키를 복구할 수 없다면 데이터 백업 후 1회 재설치가 필요합니다. 이후 동일 키로 업데이트합니다.

### 임시 테스트 배포 (v0.1.8부터)
고정 서명 Secrets 두 개가 모두 미등록이면 임시 debug 서명 APK를 pre-release로 배포합니다. 서명이 달라 기존 앱 업데이트가 실패할 수 있습니다. 두 Secrets를 모두 등록하면 자동으로 고정 서명을 사용하며, 하나만 등록한 경우 빌드를 중단합니다.

## v0.1.9 — 개발/정식 패키지 분리
- debug: `com.chaoseye.lyrilayer.debug`, 표시명 LyriLayer Dev. GitHub Releases에는 `LyriLayer-dev.apk`만 배포. 기존 `LYRILAYER_KEYSTORE_B64` / `LYRILAYER_KEYSTORE_PASSWORD`는 개발 APK 전용이며, 미설정 시 임시 debug 서명으로 배포.
- release: `com.chaoseye.lyrilayer`, 표시명 LyriLayer. `gradle :app:bundleRelease`로 서명되지 않은 AAB 생성; Actions Artifacts에서 제공. Play Console에 제출하기 전 별도 업로드 키로 서명해야 함. Play 업로드 및 앱 서명 키 생성은 자동 수행하지 않음.
- Kotlin namespace/JNI 클래스 경로는 기존과 동일. DB, 설정, 다운로드 모델, 알림 접근 및 오버레이 권한은 각각 분리. v0.1.8 이전 앱은 정식 패키지에 남으므로 자동 삭제/데이터 이관하지 않음. 두 앱의 오버레이 동시 활성화는 피할 것.

## v0.1.12 — 시작 권한 안내 / 백그라운드 재생
- 앱 시작 시 음악 접근, 알림 접근, 오버레이 권한을 확인하고 필요한 항목만 사용자에게 순차 안내. OS 설정에서 직접 허용 후 다시 확인. 거부 항목은 한 번의 요청 과정에서 반복하지 않음. 설정에서 다시 시작 가능. 일반 플로팅 스위치와 테스트 모드 설정은 유지.
- 시스템이 바인딩하는 NotificationListenerService는 앱 화면과 독립적으로 Samsung Music MediaSession 재생 상태를 읽음. 홈 및 다른 앱에서 재생 중인 동안 플로팅 유지, 일시정지/화면 꺼짐 시 숨김. 권한 유지 상태의 연결 해제 시 재바인딩 요청. OS 강제 종료, 절전/보안 정책은 예외. 실기기 확인 필요.

## v0.1.13 — 플로팅 위치 조절
- 설정 → 가사 표시 위치에서 0~100% 높이, 상단/중앙/하단 단축 버튼, 기본 위치(85%) 및 화면 미리보기 제공. 설정은 자동 저장되며 실제 가사와 테스트 문구에 함께 적용됩니다.
- 기존 100dp 고정 하단 위치를 화면 크기 기준의 상대 위치로 변경. 재생 중 기존 오버레이 위치도 즉시 갱신하고 화면 크기 및 가사 높이를 반영합니다. 실기기에서 시스템 인셋/회전 확인 필요.

## v0.1.14 — AI 가사 구분 / 실시간 미리보기
- AI 생성 가사를 보라색으로 구분하고 전체/AI 가사/미등록 필터 및 AI 생성 곡 수를 제공. 미등록 곡에서 AI 분석 직접 시작 가능. 기존 ON_DEVICE_AI 저장 데이터도 자동 구분.
- 25초 음원 구간별 Whisper 인식 결과를 LRC 시간과 함께 미리보기로 누적하고 자동 스크롤. 진행률, 인식 줄 수, 중단, 최종 검토 및 수동 저장 지원. 분석 창을 숨겨 목록에서 상태 확인 가능(앱 화면의 구성 수명 동안만, 프로세스 종료/회전 후 분석 재개는 지원하지 않음). 분석 실패/중단 결과는 자동 저장하지 않음.
- AI 가사 일반 편집 시 출처 유지, 파일/클립보드 등으로 교체 시 사용자 가사 출처 사용. 기존 DB 스키마 유지.

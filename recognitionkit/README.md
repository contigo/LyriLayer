Independent Android library, Kotlin/Java callback, ARM64, minSdk 26. Decodes up to 12 seconds per attempt at midpoint and optional quarter points. Only fingerprint and request metadata sent, never raw audio. Provider interface replaceable. ShazamProvider unofficial, disabled by default; use only with permission from service. No location collection or spoofed client identity. All HTTP errors stop batch. Build with Rust 1.95.0 and Android NDK 28.2.13676358. See NOTICE and GPL license. Device recognition not yet verified.

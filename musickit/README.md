# MusicKit
Independent Android metadata AAR; no UI, database, API key, or relay backend. Internet needed for initial lookup; the host app stores verified results. Sources: iTunes KR and MusicBrainz public APIs, optional Bugs and Genie unofficial public endpoints (can disable with createMusicKit(false); subject to provider terms/availability). No audio uploads. Automatic matches require title, artist, duration and nonempty album; competing album editions require review. Source IDs are preserved. Melon and fingerprint recognition are not implemented. AAR consumers need coroutines, OkHttp and jsoup dependencies.
